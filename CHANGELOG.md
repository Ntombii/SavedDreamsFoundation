# Saved Dreams Foundation

All notable changes to the Saved Dreams Foundation website are documented in this file.

This project follows a version-based changelog format. Changes that have not yet been included in a release are listed under **Unreleased**.

## [Unreleased]

### Added
- Implemented AJAX form submission on the Contact Us page using the JavaScript Fetch API and FormData.
- Added client-side form validation to improve the accuracy of submitted contact and enquiry information.
- Added asynchronous form submission with success and error feedback for visitors.
- Added error handling for failed form submissions and HTTP response errors.
- Improved form accessibility through appropriate labels, validation messages and status announcements.
- Added SEO configuration by updating the 'robots.txt' file and preparing the sitemap reference.
- Improved website documentation by converting 'README.txt' into a Markdown `README.md' file.
- Added and refined JavaScript interactions across the website.

### Changed
- Updated the Contact Us form to collect the visitor's name, email address, enquiry type and message.
- Improved the form submission process to provide feedback without requiring a page reload.
- Updated website documentation to reflect the actual project structure, technologies, features and setup instructions.
- Refined website content and code organisation based on testing and debugging.
- Improved consistency across the website's responsive layouts and interactive elements.

### Fixed
- Improved contact form validation to prevent incomplete or incorrectly formatted submissions.
- Added handling for unsuccessful form requests to prevent the website from displaying a success message when submission fails.
- Corrected website documentation references to match the actual HTML, CSS, JavaScript and image filenames.
- Addressed identified layout and interaction issues during website testing.

### Removed
- Removed the outdated '.github/workflows/release.yml' workflow file.

## [1.0.7] - 2026-10-02

### Added
- Added functional interactive assets and images across the website pages.
- Added comprehensive documentation comments throughout the source files.
- Added an interactive location map to the Contact Us page using Leaflet and OpenStreetMap.
- Implemented an interactive FAQ accordion on the About Us page.
- Added JavaScript functionality to expand and collapse FAQ answers.
- Added responsive styling and accessibility attributes.
- Improved responsive layouts for desktop and mobile devices.
- Added animations across website pages, designed to complete within two seconds.
- Added form validation to the Contact Us and Enquiry pages.
- Added a `robots.txt` file to provide crawling instructions for search engines.

### Changed
- Replaced information card icons with high-resolution inline images.
- Refactored the structural layout of the Home page footer.
- Updated the theme colour palette across the Enquiry page.
- Added an anchor link on the About Us page that directs visitors to the Programmes page.
- Enhanced the Contact Us page to help visitors locate the foundation's main office.
- Improved the overall consistency of the website's visual presentation.

### Updates
- Added subtle CSS transitions and JavaScript animations to images on the Home page.

### Removed
- Removed outdated vector icons from the Mission and Vision sections on the About Us page.

### Fixed
- Fixed alignment rules in the global grid layout to ensure image wrappers display consistently.
- Improved the symmetry and spacing of image-based content sections.

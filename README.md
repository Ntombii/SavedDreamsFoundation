## Project Overview
This project is the initiation and planning phase that ensures that we have a solid building foundation. I am required to research and gather data about two NPOs/small businesses that either do not have a website or have a website where I can improve the current layout and functionality. 

I then have to complete a website proposal on both and choose the one organization that I will practically create the proposed website for. I need to gather content and source information for the organization, identifying relevant content for each web page via the organization’s website (if applicable), social media, etc. 

It is important for me to create a visual representation such as wireframes just to get an idea of how the website will look and what each web page will consist of to get an overview of what will work and what won’t work. I am required to create an HTML structure of the website and use clear and consistent file naming conventions. All of this must be placed into a logical file and folder structure to ensure that the project is easier to maintain, update, and navigate.

## Website Goals and Objectives
* Increase awareness of the organization and its services.
* Attract volunteers and sponsors.
* Promote community programmes and events.
* Provide information about available support services.
* Improve communication with stakeholders.

### Key Performance Indicators (KPIs)
* Reach **1,000 website visitors** per month within six months.
* Increase volunteer enquiries by **25%**.
* Increase sponsorship enquiries by **20%**.
* Achieve a contact form completion rate of **10%**.
* Grow social media engagement through website referrals.

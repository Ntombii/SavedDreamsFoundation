Project Title: Building Foundation: Project Initiation and Planning
Student Information : ST10504583 Ntombozuko Mangcingwana
Project OverView :  This project is the initiation and planning phase that ensures that we have the building 
                    foundation. I am required to research and gather data about two NPOs, small business that 
                    either does not have a website or have a website where I can improve the current website.
                    I then have to do a website proposal on both and choose the one organisation that I will 
                    practically create the proposed website for. I need to gather content and source information
                    for the organisation. Identify relevant content for each web page via organisation’s website
                    (if applicable), social media, etc. It is important for me to create a visual representation
                    such as wireframes just to get an idea how the website will look like and what each 
                    web page will consist it just to get an overview of what will work and what wouldn’t work.
                    I am required to create a html structure of the website and use a clear and consistent file 
                    naming conventions. All of this must be placed into a logical file and folder structure to ensure that the project is easier to maintain, update and
                    navigate.
Website Goals and Objectives: Goals
             	   -Increase awareness of the organisation and its services.
	               -Attract volunteers and sponsors.
	               -Promote community programmes and events.
                   -Provide information about available support services.  
                   -Improve communication with stakeholders.
Key Performance Indicators (KPIs)
                   -1,000 website visitors per month within six months.
                   -Increase volunteer enquiries by 25%.
	               -Increase sponsorship enquiries by 20%.
                   -Achieve a contact form completion rate of 10%.
                   -Grow social media engagement through website referrals.
